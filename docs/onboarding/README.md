## 요약

- 컨테이너를 한 번 적재하고 첫 스테이지부터 rootfs 까지 **하나의 연속 실행**
- 다음 단계 적재는 펌웨어 자신의 코드가 한다. QEMU 에 커널을 직접 넘기지 않는다
- 실행 불가한 스테이지는 건너뛰되 **그 사실을 기록**한다
- 게이트 3항을 전부 통과할 때만 `VERIFIED`
